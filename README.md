# Accounting System

An offline desktop accounting program for small shops and traders, written in
Python (PySide6) with a local SQLite database. No internet or subscription is
needed for daily work, and all data stays on your computer.

The interface is available in **English** and **Urdu** (right-to-left).

## Features

**Daily work**
- Sale and purchase invoices with discount, tax, payments, returns, credit and debit notes
- Print on A4, save as PDF, print an 80 mm receipt, or send the bill on WhatsApp
- Cash In / Cash Out cash book, linked both ways with Expenses
- Party ledger with running balance, statements and WhatsApp payment reminders
- Dashboard with daily report and an overdue-bills reminder

**Stock**
- Products, stock in/out, adjustments (damage, loss, found), physical count
- Valuation at average cost, low-stock and reorder list
- Import products and parties from Excel / CSV, with a preview before saving

**Reports**
- Party Balance, Stock Report, Sales & Purchases (by month, day, party, product)
- Aging (who owes whom) and overdue bills
- Profit & Loss and Cash Flow
- Business, Ledger and Stock analytics charts
- Print, Excel and PDF export on every report

**Safety and control**
- Roles: Owner, Accountant, Cashier
- Audit log of every change; financial-year locking
- Automatic daily backup, restore with a safety copy
- Database health check
- Licensing (trial, yearly, one-time) with offline keys
